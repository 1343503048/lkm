## 概述
代理执行分离调度上下文与执行上下文。提交 `aa4f74dfd42b`（"sched: Fix runtime accounting w/ split exec & sched contexts"）使 per-task/线程组运行时间记账跟随真实执行任务，但 cgroup CPU usage 仍记到 donor。当 donor 与执行任务分属不同 cgroup 时，任务执行时间被算到不同 cgroup。本补丁主张 **cgroup CPU usage 应跟随执行上下文**（`rq->curr`），与 per-task/tg/cgroup user/system 记账一致；调度状态仍关联 donor，但 cgroup CPU usage 记到 `rq->curr`。

## 改动内容
- 将 cgroup CPU usage 的记账目标从 donor 改为 `rq->curr`（执行上下文），调度状态保留在 donor。

## 状态与讨论
- v2，多封复审（Re：78784/78769/78485/77791）。
- 注意：与 09-03 008「记到调度上下文（donor）」方向相反，二者是同一问题的两种取舍（一个主张记 donor=调度上下文，一个主张记 rq->curr=执行上下文），需关注 maintainer 最终取舍。
